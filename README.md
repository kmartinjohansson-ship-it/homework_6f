# 6F Läxkollen

En enkel, publik och mobilvänlig läxöversikt för klass 6F. Sidan är byggd för GitHub Pages och fungerar på mobil, surfplatta och en väggmonterad skärm.

## Uppdatera innehållet

Ändra läxorna i `homework.js` och datum/information i `index.html`. Lärarnas originalplanering är alltid den slutliga källan.

## Publicering

Aktivera GitHub Pages under **Settings → Pages** och välj publicering från grenen `main`, mappen `/ (root)`.
